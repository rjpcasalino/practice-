# AI Acknowledgment

This project was developed with the assistance of artificial intelligence. Large Language Models (LLMs) were used as pair-programming tools to help accelerate development in the following areas:

* **Environment Configuration:** Scaffolding and troubleshooting Nix flakes (`flake.nix`).
* **Tooling Integration:** Setting up Vim wrappers, plugin configurations, and Language Server Protocol (LSP) tooling.
* **Syntax & Boilerplate:** Generating baseline examples and resolving syntax errors.

While AI tools were used to draft configurations and troubleshoot issues, all code was reviewed, tested, and finalized by the author.
